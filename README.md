# Estacionamento do Campus — Protótipo

Protótipo em linha de comando que simula o mapa de vagas de um estacionamento
de campus (carros e motos, com vagas normal/PCD/idoso).

**Requisitos cobertos** (detalhes em `requisitos.md`): 1) exibir o mapa de
vagas livres/ocupadas; 2) permitir que aluno/servidor reporte manualmente
uma vaga como ocupada ou liberada; 3) bloquear alunos de ocuparem vagas
reservadas para servidores perto da biblioteca.

**Como executar:** `python3 main.py` (Python 3, sem dependências externas).
